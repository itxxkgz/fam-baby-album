# 暖色界面与交互约定

FAM宝贝相册使用奶油白、杏桃色、陶土橙和深可可色，图标加入少量蜂蜜色。照片保持原色，看图使用深色背景，让照片占据主要空间。

![FAM宝贝相册图标](../android/res/drawable-nodpi/fam_launcher_art.png)

公开仓库只保留实际使用的品牌资源，不附带设计阶段的家庭参考图片。展示新界面时，请使用生成的测试素材与虚构人物资料。

## 相册与成长时光

宝宝头像、名字和年龄使用紧凑布局，点击名字或头像切换宝宝。照片组以拍摄时的成长年龄为主标题，日期放在旁边，顶部资料随浏览离开。

右侧小把手表示浏览进度。轻点打开年龄或日期定位，按住拖动时照片和年龄提示实时变化，松手停在当前照片。

“从小到大”“每月故事册”、月份回忆、视频和收藏各自保留独立页面及浏览范围。没有内容时说明需要补充什么，不用演示照片冒充家庭记录。

## 二级页面与常用面板

| 页面 | 交互方式 |
| --- | --- |
| 宝宝管理 | 头像列表、编辑、收起与恢复、邀请码加入 |
| 照片存放 | 先列现有位置，再添加；已有位置显示简洁详情 |
| 云存储与 NAS | 必填项直接显示，少用配置按需展开 |
| 账号与安全 | 分别修改用户名、密码，说明设备重新登录的范围 |
| 服务器连接 | 区分服务地址与文件存放位置 |
| 家人管理 | 填称呼添加家人，用管理、上传开关调整权限 |
| 筛选、上传与留言 | 短操作使用面板，上传前明确目标宝宝 |
| 照片信息与编辑 | 故事、时间与文件信息分开，保留原件 |
| 回忆与回收站 | 保留浏览位置，说明操作的影响范围 |
| 关于与上传状态 | 显示实际版本，区分完成、失败和未完成内容 |
| 空页面与失败提示 | 区分没有内容、无权限和读取失败，提供下一步 |

一页突出一个主要操作，使用自然中文。保存失败保留填写内容，未保存离开时提醒，提交中避免重复操作。

## 看图

手机轻点收起操作，双击或双指放大后可以拖动。切换照片与视频保持正确顺序，切走或关闭视频时停止播放。

网页滚轮围绕鼠标位置缩放，放大后按住左键拖动。双击放大或恢复整张，底部保留放大、缩小和“适应窗口”，左右箭头翻页。缩放不重新创建照片，窗口变化时重新适配。

## 我的、动态与后台

“我的”优先显示家人和常用入口，存储卡只显示实际配置与占用。家人动态按连续上传合并，留言和回应对应具体内容。添加家人不会预先生成占位账号。

网页使用紧凑列表、清楚的名称和轻分隔；新增或编辑时再展开表单，照片信息使用侧栏。完整操作见[网页管理后台](网页管理后台.md)。

## 图标与可读性

- 桌面、启动和应用内品牌使用同一套 FAM 图形，功能图标使用矢量图形。
- 底部入口保留文字，选中项同时改变填充与颜色。
- 保留足够触摸范围，放大系统字体后表单与列表应随内容增高。
- 只显示有权执行的操作，必要时解释原因。
- 使用有意义的名字和日常日期，不把内部编号或程序错误直接展示给家人。
