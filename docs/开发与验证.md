# 开发与验证

服务端使用 FastAPI 和 SQLite；管理员网页后台使用原生 JavaScript 模块；安卓应用使用 Java 和安卓系统组件。业务代码在 `server`，网页在 `server/web`，手机端在 `android`，开发工具在 `tools`。

网页随服务端启动，本机地址为 `http://127.0.0.1:8765/admin/`，没有单独的前端构建步骤。Docker 镜像包含网页文件，修改后需要重新构建镜像。

## 准备开发环境

需要 Python 3.11 或更新版本、FFmpeg，以及 Node.js 22.13 或更新版本。Node.js 只用于开发测试，运行相册服务不需要它。建议在项目目录建立独立的 Python 虚拟环境。

```sh
python -m pip install -r server/requirements-dev.txt
npm ci --prefix tools/admin-web-tests --ignore-scripts
python tools/check.py
```

检查使用临时目录和虚构资料，不应指向真实家庭的数据目录、图库或云存储。完整检查会分别运行服务端、后台交互、上传导入、备份恢复和启动工具的测试；任一检查失败都会返回失败结果。GitHub Actions 也会运行这些检查，并生成源码包。

## 按修改范围检查

| 修改内容 | 重点检查 |
| --- | --- |
| 账号与邀请 | 首次改密、旧账号不重置、六位数字及前导零、过期与撤销、限制连续尝试 |
| 宝宝与家人 | 按宝宝隔离、切换时清除旧请求、管理与上传权限、撤权、共享照片、旧资料迁移 |
| 上传与存储 | 原文件不改写、拍摄时间、重复导入、存放位置复用、失败重试与权限 |
| 成长与故事册 | 代表照、素材顺序、文字署名、并发编辑、回收站与跨宝宝隔离 |
| 动态与留言 | 分组合并、筛选、分页、回复对象、重复提交与权限变化 |
| 网页后台 | 未保存内容提示、错误恢复、登录失效、跨站请求保护、批量操作和照片缩放 |
| 导入与备份 | 暂停、取消、重试、目录限制、完整性核对、独立恢复和重新登录 |

可以单独运行一组，例如：

```sh
python -m unittest discover -s server/tests -p test_admin_imports.py -v
npm test --prefix tools/admin-web-tests
```

网页检查通过模拟页面环境执行，不打开浏览器。真实 HTTP 检查会另起临时服务，在独立端口验证上传、后台任务和恢复副本，不连接正在使用的相册。

## 对象存储连接检查

准备一个仅供测试的 S3 兼容服务、独立存储桶、可读写账号和只读账号。把连接资料保存在仓库外的配置文件，通过 `ALBUM_S3_TEST_FIXTURE` 指定文件位置。字段和测试流程见 `server/tests/test_storage.py` 的真实连接测试。

没有提供配置时，这部分检查会明确跳过。阿里 OSS、腾讯 COS 的真实云端连接需要分别验证，不能用本地 S3 测试代替。不要把测试密钥提交到仓库。

## 安卓构建

按 [README](../README.md) 准备 PowerShell 7、JDK 21、Android SDK 平台 36 与构建工具，然后运行：

```powershell
pwsh -File build.ps1
```

生成的安装包在 `dist`。构建会先执行邀请解析、翻页手势、浏览位置、故事册排序、宝宝切换、年龄定位、拖动实时浏览、家人权限与存储保存等十二组 Java 检查，再编译、签名并检查安装包。检查失败会停止构建。

需要安装到已连接的模拟器时，加 `-Install`；多台设备可用 `-Device` 指定。仅构建不会操作模拟器。第一次构建会在 `.private` 生成自己的签名，签名和密码应私下备份，后续更新沿用同一份。自己的签名不能覆盖官方安装包。

本机工具不在标准 SDK 目录时，可以在不提交的 `.private/build-tools.json` 中指定 `java_home`、`android_jar`、`aapt2`、`r8`、`zipalign`、`apksigner` 和 `adb`。这些路径只适用于本机，不属于发布源码。

Java 排版可选。自行安装 Google Java Format 的完整 JAR 包后，运行 `pwsh -File format-java.ps1 -FormatterPath <工具路径> -Check`。省略 `-Check` 会修改排版；本版代码使用 1.37.0。

## 实际操作验收

自动检查不替代真机触控、视频播放和界面观感。使用独立测试相册与生成的照片、视频，建议核对：

1. 新相册首次改密、已有账号升级后登录，以及修改账号后其他设备重新登录。
2. 两位宝宝之间切换，按宝宝邀请家人，开启和关闭权限，确认没有串入另一位宝宝的照片或草稿。
3. 手机连续翻页、缩放、退出后恢复位置，拖动右侧年龄滑块时照片实时跟随；视频切走后停止播放。
4. 网页滚轮缩放与拖动、筛选与批量整理、窄窗口和键盘操作，以及保存失败后保留输入。
5. 动态分组、回应照片、回复留言，成长代表照和故事册整理，以及两人同时编辑时的冲突提示。
6. 小批量导入、换存储后读取旧照片、完整备份与独立恢复。核对原件、日期、留言、家人权限和故事册。

没有执行的验收项目应明确记录，不把自动检查通过当成真机已验证。真实家庭截图、邀请码、云密钥和成员资料不能加入公开仓库。

## 生成源码包

```sh
python tools/package_source.py
```

脚本按明确清单生成 `dist/FAM宝贝相册-开源源码.zip`。包含程序、测试、说明、品牌资源和经过核对的公开设计图，不包含数据目录、个人配置、签名、私人设计参考图和模拟器截图。公开设计图只从 `docs/design/public` 中的明确清单选取，不能将整个私人设计目录复制进来。

发布前在空目录解压，重新安装依赖并运行检查，确认没有依赖未分发的文件。检查新增文件是否需要加入打包清单；不要直接压缩整个开发目录。

当前功能边界见 [版本说明](版本说明.md)，数据保存与恢复见 [备份与升级](备份与升级.md)。
