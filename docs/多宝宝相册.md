# 多宝宝相册

FAM宝贝相册可以在同一个家庭中为多位宝宝分别保存成长记录。当前安卓 App 为 2.10.0，服务端与网页后台为 2.9.2。从早期版本升级的方法见 [备份与升级](备份与升级.md)。

每位宝宝有自己的名字、生日、头像、相册、回收站、家人动态、成长代表照和每月故事册。家人使用同一个账号，能看到哪些宝宝、能做哪些操作，由家庭管理员或对应宝宝的管理员设置。

## 新建和切换宝宝

在 App 相册顶部点宝宝头像或名字，就能打开宝宝列表；也可以从“我的 → 宝宝相册”进入。选择一位宝宝后，相册、时光、动态和回收站都切换到这位宝宝。退出账号时会清除已选择的宝宝，换账号不会继续显示上一位家人的内容。

宝宝列表用头像、名字和年龄区分各个相册；点击宝宝用于切换，编辑与收起放在更多操作中，已收起的宝宝另行查看。家庭管理员可以在宝宝列表中新建相册，填写名字和生日。生日可以暂时不填，之后补齐再查看按年龄整理的成长记录。头像可以从这位宝宝相册中尚未移入回收站的照片选取。修改宝宝资料不会修改家庭相册名称。

网页后台仍是六个入口，在“宝宝与家人”中新增和编辑宝宝；“设置”中也可以编辑当前宝宝资料。页面上方的宝宝选择决定当前浏览和整理的范围。存储、备份、上传大小限制及家庭相册名称仍是整个家庭的设置，不会随宝宝切换。

切换时会重新读取所选宝宝的内容，旧列表、翻页位置和未发送的留言不会带到另一位宝宝。重要草稿请先保存或复制。若访问权限被收回，应用会重新选择仍能访问的宝宝；没有可访问的宝宝时会说明原因，可以接受邀请重新加入。

## 谁可以看到哪些宝宝

“家庭管理员”是整个家庭的身份，“宝宝管理员”“可上传”“仅查看”是某一位宝宝相册中的权限。两者分别管理。

| 身份或权限 | 可以做什么 |
| --- | --- |
| 家庭管理员 | 管理所有宝宝、家庭账号、存储和备份；使用网页后台；新增宝宝、归档和恢复宝宝相册 |
| 宝宝管理员 | 管理被授权宝宝的资料、照片、邀请和家人访问范围；不能因此进入网页后台或管理其他宝宝 |
| 可上传 | 浏览、下载、收藏和留言；上传内容，整理这位宝宝的成长代表照和故事册；修改、移入回收站或恢复自己上传的内容 |
| 仅查看 | 浏览、播放、下载和管理自己的收藏；看成长记录与故事册，临时制作成长对比图；不能上传或留言 |

同一位家人可以在一位宝宝的相册中“可上传”，在另一位宝宝的相册中“仅查看”，也可以完全没有访问权限。新建宝宝不会自动把普通家人都加入；家庭管理员始终能管理所有宝宝。

调整某位家人的宝宝访问范围，只影响对应宝宝。停用家庭账号会让这个账号退出登录，也停止访问其他宝宝。宝宝管理员可以调整已经加入该宝宝的家人权限，新家人通过邀请加入；不能自行降低或移除自己的管理员权限。家庭管理员身份也单独设置，不会因为被邀请成为“宝宝管理员”而自动获得。家庭必须保留至少一位可登录的家庭管理员。

## 邀请家人

点“添加家人”，只填写与宝宝的关系，即可生成邀请。默认只开放当前宝宝的查看权限，有效期为24小时。家人加入后，点开“家人信息”，用“管理”和“上传”两个开关调整当前宝宝的权限。两个都关时仅查看；管理包含上传，关闭管理后仍保留上传权限。只能邀请对方加入自己有权管理的宝宝相册。

同一位家人与不同宝宝的关系可以分别填写；只修改当前宝宝的称呼，不更改账号名或历史上传记录。需要加入另一位宝宝时，切换宝宝再邀请，已有账号可直接接受。家庭管理员仍可通过独立的账号管理安排多个宝宝的访问范围、设置家庭身份或停用账号，这些选项不放在日常添加流程中。

没有账号的家人在登录页接受邀请并创建账号；已经有账号的家人可从宝宝列表选择加入已有宝宝相册，使用邀请加入，不必再注册。一次性邀请有使用期限，也可以在使用前撤销。撤销未使用邀请不会收回已经授予的权限；已加入家人的访问范围要在家人管理中调整。

## 合照可以同时放在几个相册

上传前可以选择一位或多位自己有上传权限的宝宝，默认选择当前宝宝。兄弟姐妹的合照可以同时加入各自的相册，**服务器只保存一份原文件**。

有权编辑这份共享照片并能向目标宝宝上传时，已有照片也可以在详情的更多菜单选择“添加到其他宝宝相册”；网页后台可勾选照片后批量添加。原来的相册归属会保留。后台导入发现相同文件时，可以把它加入尚未收录这份内容的目标宝宝，不再保存一份原件。已经在目标宝宝回收站中的内容不会被偷偷恢复，需要到对应回收站恢复。

共享照片的拍摄时间和原照片说明属于同一份文件记录。修改后，所有关联宝宝的相册都会更新。只有对所有关联宝宝都具备这份照片编辑权限的家人才能修改；操作前会提示同步影响。更正相册时间和说明不会改写原文件。

以下内容分别保存：

- 在某位宝宝相册中移入回收站或恢复，只改变这位宝宝的收录状态，其他宝宝仍可正常查看。
- 留言、回复和家人动态属于当前宝宝。同一张合照在不同宝宝相册中的留言分别显示。
- 成长代表照按各自生日计算和选择；故事册的标题、文字、封面和顺序也分别保存。
- 收藏属于“这个账号喜欢这份照片”，不是每位宝宝各自一份收藏；只会在该账号能够访问且当前宝宝仍收录这份照片时显示。

各宝宝的照片数量可以重复包含同一张合照，不能直接相加当作原文件数量或实际硬盘占用。

## 暂时收起一个宝宝相册

家庭管理员可以归档宝宝相册。归档保留资料、原件、留言、故事册和家人权限，不等于删除，也不能代替备份。普通家人的宝宝列表会隐藏已归档相册；家庭管理员可以查看已归档的资料，并在需要时恢复。归档期间先恢复相册，再继续编辑。

至少要保留一位未归档的宝宝。恢复归档只能由家庭管理员操作，恢复后按原来的访问范围继续使用。

## 旧相册升级后会怎样

第一次启动 2.8.0 服务端时，已有资料会一次性归到原来的宝宝名下。原照片、回收站、家人关系、留言、动态、成长代表照和故事册都会保留，原文件不搬迁。原账号、密码和现有登录继续有效，不会重新变成默认账号。

旧邀请只对应原来的宝宝，不会自动授予后来新增宝宝的访问权限。升级之后再按需要新增宝宝、调整家人访问范围。

旧版 App 没有宝宝选择信息，只能使用服务端默认的可访问宝宝，不能完整使用多宝宝功能。请让家人的手机与服务端一起更新到 2.8.0。完整备份会保存全家庭所有宝宝及其关系，包括已归档相册；恢复仍生成独立副本，详见 [备份与升级](备份与升级.md)。
