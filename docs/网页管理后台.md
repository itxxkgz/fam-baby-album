# 网页管理后台

网页后台方便家庭管理员在电脑上整理相册，使用与 App 相同的账号、宝宝、家人资料和照片。六个入口已同步采用更简洁的暖色布局，配合 2.12.0 App 使用；服务端接口仍为 2.9.2。

网页后台随相册服务提供，地址是在服务网址后加上 `/admin/`。从源码启动时，服务直接读取 `server/web` 中的文件；使用 Docker 时，修改网页后需重新构建并更新容器。已有相册应沿用原数据卷与配置。

## 打开与登录

启动本机服务后，在浏览器打开 `http://127.0.0.1:8765/admin/`。部署到服务器后，在相册服务地址后加 `/admin/`。Docker 也由原来的相册服务提供网页，不需要增加另一个网站或端口。

只有家庭管理员可以进入。宝宝管理员只负责被授权的宝宝，不能凭这一权限进入网页后台。全新相册的用户名和初始密码都是 `admin`，首次登录会要求先设置一个 8～200 个字符的新密码，完成前不能查看或管理相册。已有相册继续使用原账号，升级、重启都不会重置成默认密码。如果部署者选择首次设置口令方式，登录页会提示创建管理员。

浏览器通过 Cookie 保存登录，登录凭据不能被页面脚本直接读取；修改操作还会校验请求是否来自当前后台。浏览器与 App 各自保持登录。修改用户名或密码后，当前页面继续登录，其他设备需要重新登录。远程使用时，请沿用相册服务的 HTTPS 地址。

## 六个入口

| 入口 | 可以做什么 |
| --- | --- |
| 概览 | 查看当前宝宝的照片、视频和家人数量、最近上传、本周新增、服务器可用空间与最近备份；快捷进入导入和家人邀请 |
| 照片与视频 | 默认显示常用筛选；从侧栏查看照片信息、修改单项或批量时间与说明；添加到其他宝宝相册、下载原件、移入当前宝宝回收站及恢复 |
| 导入与任务 | 先选择电脑或服务器目录；上传文件或文件夹，查看进度与结果，暂停、继续、取消或重试服务器任务的失败项 |
| 宝宝与家人 | 使用紧凑列表切换和管理宝宝，单独查看收起的宝宝；弹窗邀请家人，管理当前宝宝权限；从独立账号入口管理跨宝宝访问、家庭身份和账号停用 |
| 存储与备份 | 分为存放位置、备份计划和备份记录；配置自己的服务器、NAS、OSS、COS、通用 S3，选择新上传位置，创建备份、下载、核对和恢复副本 |
| 设置 | 分为基础设置、账号与安全、关于相册；修改家庭相册名称、上传大小上限和自己的登录信息，宝宝资料入口转到宝宝管理 |

宝宝名字、生日和头像统一在“宝宝与家人 → 宝宝管理”编辑。“设置 → 基础设置 → 宝宝资料”会转到这个入口，不再重复放一份宝宝表单。已收起的宝宝需先恢复再编辑；全家庭上传限制等设置仍可使用。

页面上方可以切换宝宝，概览、照片和回收站跟随所选宝宝。切换会清除旧页面的选择和浏览范围；有未保存的填写内容时先确认，正在提交时等待完成。存储、备份、上传大小限制与家庭相册名称属于整个家庭，切换宝宝不会切换这些设置。详细规则见 [多宝宝相册](多宝宝相册.md)。

右上角的运行记录汇总相册整理、账号或设置修改，以及最近的导入和备份结果，方便查看需要处理的事情。

## 整理照片和视频

点开照片后，可用鼠标滚轮连续放大或缩小，缩放围绕鼠标所在位置进行；放大后按住鼠标左键拖动，查看照片的其他部分。双击可放大，再次双击恢复整张显示；底部也有放大、缩小和“适应窗口”按钮。缩放最高为整张显示时的 8 倍，到边缘会停止拖动，避免照片移出画面。

左右箭头切换照片，切到下一张会恢复整张显示。键盘左右方向键可以翻页，`+`、`-` 调整缩放，`0` 恢复整张。触屏在整张显示时左右滑动翻页，放大后拖动查看，也可以用双指缩放。视频继续使用播放器自己的控件，不接管它的滚轮和拖动操作。

打开“照片与视频”，先筛选内容，再勾选要处理的照片。上传家人、日期等较少使用的条件按需展开。可以选择当前页，也可以逐张选择；翻页或重新筛选会清除当前选择，避免误操作。

点照片上的“信息”从侧栏查看拍摄时间、上传家人和文件资料；有权限时可以继续编辑。单项与批量编辑沿用同一套侧栏，保存失败时保留填写内容，关闭未保存的编辑前会询问。

“修改时间与说明”只保存勾选的项目。勾选统一修改时间后，所选内容都会使用填写的新时间；修改说明同理。相册里的显示和排序会更新，原照片和视频文件保持原样。共享照片的时间和原照片说明会同步更新所有关联宝宝；确认前会提示影响范围，服务端要求对全部关联宝宝都有相应编辑权限。

“下载原文件”会打包所选内容，并附上拍摄时间、上传家人和照片说明。下载原件不等于备份整个相册；要保留家人、收藏、留言和故事册等关系，请使用“存储与备份”。

“添加到其他宝宝相册”保留原来的归属，把选中内容加入指定宝宝相册，原文件仍只存一份。

移入回收站或恢复只改变当前宝宝的收录状态，不影响其他宝宝。留言、回复和成长记录按宝宝分别保存。本版后台没有永久清空回收站的操作。

## 从电脑导入

1. 在“导入与任务”选择“从电脑导入”，再选目标宝宝，选择文件、选择文件夹，或把文件拖到上传区域。一次最多选择一万份；常见照片格式和 MP4、MOV、M4V、3GP 视频可导入。
2. 文件会先传到服务器。**这一阶段需要保持页面打开**，进度显示已传输数量和大小。
3. 所有文件传好后，页面会自动开始服务器导入。看到“文件已传好”后，即使关闭浏览器，导入也会继续。
4. 回到任务列表查看结果。完全相同的文件如果已在所有目标宝宝相册中，会跳过；尚未收录这份内容的目标宝宝会新增关联，原文件不重复保存。已有回收站关联不会自动恢复，结果会提示去对应宝宝回收站处理。

任务使用创建时选定的宝宝，即使后来切换页面顶部的宝宝，已创建任务的目标也不会改变。任务运行时仍检查目标宝宝是否可写；宝宝被收起或权限变化时会说明失败原因。列表先显示任务状态与结果，需要时再展开具体说明或打开任务详情。

上传中断或主动停止传输时，已经传好的文件仍保存在任务里，可以点击“开始导入”先处理这一部分。尚未传到服务器的文件需要重新选择；当前不支持关闭浏览器后接着传剩余字节。

原文件中的拍摄时间优先保留；没有可用原拍摄时间时，电脑文件时间会作为备用信息。文件内容不改写。文件最终存到处理时选用的新上传位置，导入中的文件夹层级不会建立成新的相册分类。

## 从服务器目录导入

照片已经放在服务器上时，选择“从服务器目录导入”，选定部署者允许的目录，可填写其下的子文件夹。先扫描查看数量、大小和重复内容，选择目标宝宝，再确认开始。目标宝宝会随任务保存，切换页面不改变正在导入的范围。

默认可读服务器图库；额外目录由部署者通过 `ALBUM_IMPORT_ROOTS` 配置。网页不能任意浏览服务器，也不能通过上级目录、隐藏目录或符号链接绕到其他位置。单次扫描最多检查一万个文件，大目录请按子文件夹分批导入。配置方法见 [部署与存储](部署与存储.md)。

目录导入会读取并复制原文件到所选存放位置，不移动或删除来源文件。处理期间请保持来源目录可用，不要同时修改文件。

## 暂停、继续与重试

暂停或取消时，正在处理的一份文件会先完成，然后停止下一份。暂停的任务可以继续；取消后，已经进入相册的内容仍会保留。失败结果会说明问题，修复存储连接、文件或空间问题后，可以只重试失败项。

服务重启后，上次处理中断的任务会显示为暂停，点击“继续”接着处理。任务和已接收文件保存在服务器数据目录里，因此升级时也要保留原数据目录。

## 宝宝、家人和账号

“宝宝管理”默认列出正在使用的宝宝，当前宝宝标注“正在看”。查看相册或切换宝宝直接在列表操作，编辑资料与收起放在更多入口。“收起的宝宝”单独列出保留的相册，需要时可以恢复。

家庭管理员点“添加家人”打开简短弹窗，只填写与宝宝的关系，例如“奶奶”或“小姨”，即可生成一次性邀请。默认只查看当前宝宝，有效期为24小时，不再显示“更多设置”，也不在家人名单旁常驻邀请表单。

新邀请码是六位数字，点击“复制邀请码”即可单独复制；第一次连接服务器的家人可以使用“复制完整邀请”。六位数字中的零也会原样保留。使用邀请码加入时仍可粘贴以前的长码，或从完整邀请中读取邀请码，不需要重新生成所有旧邀请。

主列表显示当前宝宝的家人，点开“家人信息”可修改关系，或用“管理”和“上传”两个开关调整权限。开启管理会开启上传；关闭管理后保留上传，两个都关闭时仅查看。修改会立即保存，失败时恢复原来的状态并提示重试；读取中的旧页面不能修改新选择的宝宝。“移出宝宝相册”只收回当前宝宝的访问权限，不删除账号或原照片。

家人主列表只显示已加入账号。“等待加入”和“历史上传者”按需展开，未注册的旧上传者不会混进已加入名单，也不删除其照片、点赞或原上传关系。需要邀请本人认领时再关联，没有账号的家人在 App 注册，已有账号可以接受邀请加入所选宝宝。邀请码只在生成时显示，请当时复制；尚未使用的邀请可以撤销。只是生成邀请时不会先创建一个占位家人。

家庭身份与每个宝宝的访问权限分别管理。同一位家人可以管理一位宝宝、只查看另一位宝宝，或不加入其他宝宝。家庭管理员能管理所有宝宝，新宝宝不会自动授权给普通家人。从“全家庭账号”进入账号管理，再打开对应家人的“账号设置”，安排宝宝访问、家庭身份或停用账号；移出所有宝宝的账号也仍能从这里找到。

收起宝宝会保留照片、家人权限、留言和故事册，普通家人暂时看不到。只有家庭管理员能恢复；收起期间不能编辑，至少保留一位正在使用的宝宝。

停用账号会让该家人退出登录，已有照片与留言保留；恢复使用后可以用原账号重新登录。不能停用自己或撤掉自己的管理员权限，也不能让相册失去最后一位可登录管理员。

“设置 → 账号与安全”修改的是当前管理员自己的登录信息，不会重置其他家人的密码。用户名改变后，家人称呼、上传归属、收藏和留言保持不变。

## 存放位置与备份

三个标签分别处理“存放位置”“备份计划”和“备份记录”。存放位置先列出已有配置，添加时再选择存放方式；已有位置从“查看设置”进入，不在列表堆放配置表单和多个操作。

存放位置是全家庭共用的设置，决定各宝宝的新照片存在哪里；切换位置不会自动搬迁已经上传的照片。NAS 要先由服务器挂载，OSS、COS 和 S3 的访问密钥只保存在服务端。已有密钥留空表示继续使用，不会显示原密钥。

备份可以手动创建，也可以按每天或每周的计划执行，时间使用北京时间。计划和手动备份都在服务器处理，不需要保持网页打开。

**所有后台备份目前都保存在服务器数据目录下的 `backups` 文件夹**，不会自动同步到 NAS、OSS、COS 或其他云存储。完成后可以下载到另一台设备，另存一份。完整备份覆盖所有宝宝，包括已收起宝宝、家人权限、共享关系、留言、成长记录和故事册，以及全部原照片、视频；“仅相册资料”不包含原照片和视频，恢复时仍依赖原存储。

“恢复副本”需要当前管理员密码，会在服务器上生成独立副本，当前相册不被覆盖，也不会自动切换。完整恢复的原件保存在副本本地；仅资料恢复还需接回原文件。启用副本由部署者按生成的说明完成，详见 [备份与升级](备份与升级.md)。

上传大小设置对全家庭统一生效，同时用于 App、电脑上传和服务器目录导入，不能超过部署时设定的上限。服务器空间不足或文件无法读取时，应先处理原因，再继续任务。

## 保存与离开页面

表单和编辑侧栏沿用一致的保存方式：正在提交时防止重复点击和意外关闭，未保存时可以选择继续填写或放弃，失败时保留内容并说明下一步。关闭网页或刷新时，有未保存或正在提交的内容也会提醒。登录已经失效时仍需重新登录，不会因为保留弹窗而继续允许操作。

网页交互与缩放计算的自动检查方法见 [开发与验证](开发与验证.md)。自动检查不替代实际设备上的操作验收；部署后请用测试照片确认上传、看图、权限和备份流程。
