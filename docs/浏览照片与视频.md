# 浏览照片与视频

以下说明适用于 FAM宝贝相册 2.6.2。成长代表照和故事册由服务器保存；从 2.5.0 升级可以继续使用原服务端，更早版本的升级方法见 [备份与升级](备份与升级.md)。家人动态里的分组浏览与照片回应另见 [家人与动态](家人与动态.md)。

## 在相册里找照片

相册顶部显示宝宝名字、现在的年龄，以及照片、视频和家人的数量。每一天的分组先显示孩子当时的年龄，旁边是拍摄日期。

往下翻时，顶部资料会随列表离开，把空间留给照片。需要筛选或上传时，稍微往回滑即可看到操作；回到列表开头也能使用这些入口。底部的相册、时光、动态和我的始终便于切换。

点击筛选，可以选择照片或视频、只看自己的收藏，以及按月份查找。正在筛选时，顶部会说明当前范围，点击“查看全部”回到完整相册。也可以切换大图或小图排列。

## 在时光里慢慢回看

“时光”的几个入口分别打开独立页面：

- **从小到大**：按年龄翻看成长代表照，比较两个年纪，也可以连续播放照片。
- **每月故事册**：用照片作封面，把一个月的照片、视频和故事收在一起，像翻书一样回看。
- **视频回忆**：集中浏览已经上传的视频，点开即可播放并继续滑动看前后内容。
- **月份回忆**：先选择月份，再进入这个月的照片和视频。
- **我的收藏**：查看自己收藏的内容，每位家人的收藏分别保存。

首页的成长照片卡可以直接进入“从小到大”，最近月份的故事书封面可以直接打开对应月册。想查找其他故事册，点“全部故事册”；视频回忆、月份回忆和我的收藏在下方的插画入口中。

这些页面仍属于“时光”，不会替你切换到相册或改掉相册原来的筛选。查看大图后返回，会回到刚才的页面与位置；从月份内容返回，会回到打开它的月份目录或时光首页。

“从小到大”与“每月故事册”的具体选片、对比和整理方法见 [成长与故事册](成长与故事册.md)。

“视频回忆”用于回看已有视频。“从小到大”的连续播放则按年龄播放代表照片，两者都不会自动剪辑或导出成长短片。

## 连着看照片

在相册里轻点一张照片，即可打开大图。向左滑看下一项，向右滑看上一项，手指移动时就能看见前后画面。滑得较短时松手会回到原处；翻到开头或结尾会轻轻回弹。

浏览可以跨过拍摄日期，不用每看完一天就退出。若从收藏或筛选结果打开，连续浏览会沿用当前范围；从成长记录或故事册打开大图，会沿用该组回忆的范围。想看其他内容，先返回原来的页面调整选择。

轻点照片可以收起日期和操作，再轻点即可显示。界面收起时，照片大小不会改变。返回时可使用返回按钮、安卓返回操作，或在照片未放大时明显向下拉动；轻拉后松手会回到原处。

## 看清细节

- 双击想看清的位置，可以放大；再次双击恢复完整画面。
- 两根手指张开或捏合，可以继续调整大小。
- 放大后用一根手指拖动，查看画面的其他位置。此时左右拖动用于看细节，恢复完整画面后再翻页。

打开照片时会先显示预览，再换成更清晰的画面。如果已经开始放大查看，同样比例的原图到达后会保留观察位置。横竖屏切换时，照片会重新适配新的屏幕方向。

## 看视频和保存原文件

视频和照片可以在同一个序列中浏览。进入视频后会开始播放，画面底部可以暂停、继续播放或拖动进度。播放时静置片刻，操作会自动收起；轻点画面可再次显示。切到其他照片或退出浏览后停止播放。横竖屏切换会保留播放位置。

网络较慢时可能需要等待加载；无法播放时先检查手机与相册服务器的连接。

照片和视频都可以保存原文件。预览只用于更快地显示画面，不会替换服务端保存的原件。相册中人工更正的拍摄时间、故事和留言单独保存在相册资料中，不会改写原文件，因此备份时也要保留服务端数据目录。

每位家人的收藏各自保存；可以修改哪些说明、能否移入回收站，取决于管理员授予的身份和内容上传人。具体权限见 [家人与动态](家人与动态.md)。
